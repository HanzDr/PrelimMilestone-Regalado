# PrelimMilestone-Lastname

A responsive, accessible, multi-page student portfolio built with HTML, CSS, and JavaScript.

## Pages

- Home / Hero (`index.html`)
- About Me (`about.html`)
- Projects / Gallery (`projects.html`)
- Contact (`contact.html`)

## Setup

1. Serve this folder with a local web server (for example, VS Code Live Server) to avoid browser restrictions on local files.
2. Open `index.html` through that server.

The projects page includes the live Samahan Website 2026, UFest Palaro 2025, PyCon Davao, and MH Telematics projects, plus the in-progress Cateneo project. It also checks real project data through the GitHub REST API. Only the selected projects are displayed, and every entry is dynamically rendered. The gallery includes partial-name search, pagination, and bookmarks saved in `localStorage`. The contact form validates Philippine mobile numbers in `09XXXXXXXXX` or `+639XXXXXXXXX` format.
